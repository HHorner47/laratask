## 1. プロダクトの紹介

講義で作成した SNS アプリケーション「Laratter」をもとに，タスク管理アプリをベースにしたSNSアプリケーションを作りました．

- 自分のタスクの作成、削除、編集、完了ができる
- 自分のタスク予定時刻の30分前にgmailで通知が来る
- マイページでこれまで完了したタスク数などがわかる

タスク管理のSNSを作成した理由は、laravelのスターターキットに入っている認証の仕組みとタスク管理アプリをうまく融合させられる考えたからです．

## 2. こだわった点・苦労した点

- タスクの完了、未完が分かりやすいように予定時刻と完了しているかの状態に合わせて色を変えるようにした
- 毎分予定時刻の30分より前のタスクを確認してまだ行われてない通知処理を行うようにした
- 通知の作成方法などが分からなくて苦労したが、調べながら試行錯誤をして解決した

## 3. 操作方法

1. トップページから「ログイン」または「新規登録」を行う
2. 「Task作成」から自分のタスクを作成する
3. 「Task一覧」または「マイページ」から，「complete」ボタンを押す
4. タスクの予定時刻が緑色になったこと、自分の完了タスク数が増えたことを確認する
5. 自分のタスクの下のほうにある「cancel complete」ボタンを押すと完了しタスクが未完に戻る

## 3.5. メール通知
1. .envファイルのmailに関する部分を以下のように書き換える
- MAIL_MAILER=smtp
- MAIL_HOST=smtp.gmail.com
- MAIL_PORT=587
- MAIL_USERNAME=あなたのgmailアドレス
- MAIL_PASSWORD=アプリパスワード（作成する必要あり）
- MAIL_ENCRYPTION=tls
- MAIL_FROM_ADDRESS="あなたのgmailアドレス"
- MAIL_FROM_NAME="${APP_NAME}"
2. ターミナルで以下のコマンドを動かす
```bash
./vendor/bin/sail php artisan schedule:work
```
3. ユーザー登録しているメールに未完了かつ、期限が近いタスクがあると通知が送信される
（提出した動画にはgmailの通知を確認するために自分のgmailを利用したアカウントを利用しています）
